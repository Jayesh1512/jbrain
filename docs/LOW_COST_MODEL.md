# Low-cost model configuration (2026-10-26)

The EPL trial daemon is configured with `gpt-6-luna` for both answer generation and verification. The launcher now pins both roles to that model by default, overriding an old `JBRAIN_MODEL` or `JBRAIN_VERIFIER_MODEL` inherited from the shell. Start it with `python3 scripts/epl_trial.py start --key-file /absolute/path/to/private/provider-key`. The key file remains outside the repository. The storage and native evidence APIs work without any model calls.

This change follows the user's cost constraint. [OpenAI's current model page](https://developers.openai.com/api/docs/models/gpt-6-luna) lists standard text rates per million tokens of **$0.10 input, $0.01 cached input, $0.125 cache writes and $0.50 output**. It supports the Responses API, function calling and structured outputs used here. [GPT-4.1 nano was shut down on 2026-10-23](https://developers.openai.com/api/docs/deprecations), so it is not a viable replacement even though it may still appear in model-list responses.

The [historical Astra baseline](LIVE_BASELINE_RESULTS.md) cost an estimated **$6.6677 for 24 questions**, including planner and verifier calls. Applying Luna's listed rates to *exactly those historical token counts* gives **$0.0667 for 24**, or roughly **$83/month at 1,000 questions/day**. This is a price-only counterfactual, not a Luna measurement: a different model can use a different number of calls and tokens, and provider failures can lack usage receipts. Hosting and ingestion are excluded.

The first live Luna hard-question smoke test (2022/23 away-goal leader) used five metered calls and an estimated **$0.001305**, but returned `INVALID_CITATIONS` and no accepted answer. A simpler match-winner question answered correctly with valid citations in nine calls, an estimated **$0.001907**, and **45.66 seconds**. These two probes establish provider compatibility and low individual bills, not representative accuracy, latency or monthly spend. The high call count even for a simple question is a remaining efficiency problem. Compare Luna against independently reviewed development cases and the frozen holdout before claiming the >97% target.
